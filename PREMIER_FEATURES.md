# Premier Wheels signature features

## PremierScore
A transparent rule-based comparative indicator, not an objective "best car" ranking.
Weights: price competitiveness (30), mileage for age (20), age (15), photos/presentation (15),
listing completeness (15), seller information (5). Price comparisons prefer same make/model
and fall back to similar fuel/transmission/price-range listings when enough comparable data exists.

## PremierMatch
A transparent buyer-preference match using budget (30), fuel (20), transmission (15),
minimum year (10), maximum mileage (10), location (10), and the buyer's selected priority (5).

## Ownership Estimate
A client-side calculator using user-editable annual kilometres, fuel/energy price,
efficiency, optional insurance, and optional maintenance. Results are planning estimates.
